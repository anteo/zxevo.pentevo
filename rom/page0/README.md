# rom/page0 — стартовая сервисная страница (`services.rom`)

Первая страница ПЗУ EVO Reset Service (`ROM_ERS` = страница 0). Именно она оказывается в окне 0
после включения/сброса компьютера, и именно она решает, **что будет загружено дальше**: главное меню
ERS, BASIC 48/128, TR‑DOS, CMU Setup, демонстрация `GRASS`, внутренний отладчик, альтернативная
прошивка (GLUK / ProfROM / Custom ROM) или включённый резидент.

Сборка: `source/build.sh` → `../services.rom` и `../services_fe.rom` (16 Кбайт).

Сервис `RST 8` (страницы 5..9) описан в [`../page5/README.md`](../page5/README.md).

---

## 1. Зачем нужна

`services.rom` — это «точка входа» всей прошивки. Её задачи:

1. **Инициализация железа и конфигурации памяти** — минимальный набор после сброса: стек, `I`,
   `IM 1`, бордюр, обе таблицы страниц проецирования (мапперы), палитра.
2. **Инициализация сервиса `RST 8`** — вызов `INSTALL_NMIRST` (страница `ROM_RST81`): обработчики
   `RST 8`/NMI, страницы переменных, шрифт, DRAM‑таймаут HDD, проверка CMOS.
3. **Разбор клавиш, удерживаемых при сбросе** — «горячий» выбор режима без меню.
4. **Выбор прошивки** по настройке в CMOS (`0xED`, биты 1‑0): ERS, GLUK, ProfROM, Custom ROM.
5. **Запуск главного меню ERS** (страница `ROM_MAINMENU`) или демонстрации `GRASS`, CMOS Setup,
   внутреннего отладчика.
6. **Поддержка резидента Honey Commander** — проверка сигнатуры в странице `0x1F` и передача ему
   управления при сбросе.
7. **Стабы `RST 8`** (`0x0008` → `DOS2RST8`, `0x3CE8` → `EDOS2RST8`) — через эту страницу проходят
   все вызовы `RST 8`, когда она стоит в окне 0 (главное меню, загрузчики).
8. **Точка входа сервисной страницы** `0x3D2D` (`OUT (C),A; NOP; RET`) — тот же контракт, который
   требуется от Custom ROM / GLUK: сюда переходит управление после выбора страницы из конфигурации.

### 1.1. Что стоит в окне 0 после сброса (с какой страницы стартует машина)

Да, старт идёт **со страницы 0 ПЗУ** — то есть с этой самой страницы (`ROM_ERS = 0`,
`services.rom`). Механизм:

1. **FPGA после сброса держит диспетчер страниц выключенным**: в `z80/zports.v` `atm_pen` (он же
   `pager_off` в `mem/atm_pager.v`) инициализируется в `1`, а в `atm_pager.v` при `pager_off`
   принудительно выставляется `romnram = 1` (ПЗУ) и `page = 0xFF`. По документации
   (`docs/zxevo_base_configuration.pdf`, порт `#xx77`, бит A8): «если 0, то выключение диспетчера
   памяти. В каждое окно процессора устанавливается последняя страница ПЗУ. 0 после сброса». То есть
   до первой записи в порты **все четыре окна указывают на одну и ту же — последнюю — страницу
   ПЗУ**, поэтому нет ни RAM, ни BASIC/TR-DOS.
2. **Последняя страница ПЗУ = страница 0 в нумерации прошивки**: `rom/build_full.sh` ставит блок ERS
   последним, и в собранном `rom/zxevo_fe.rom` сервисная страница лежит по смещению `0x7C000`
   (подпись `HEGLUK` в конце файла). Отсюда правило нумерации: «страница N» прошивки = `(31 − N)`-й
   16‑К слот микросхемы.
3. **AVR страницу не выбирает.** В `avr/baseconf/src/zx.c` (`zx_init`) есть только
   `zx_spi_send(SPI_RST_REG, 0, 0)`, а `fpga/baseconf/slave/spi_fmt.txt` прямо говорит: «регистр
   `$30` — регистр сброса — задаёт сам факт сброса Z80… данные в игнор». Роль AVR в старте другая:
   он держит PS/2→ZX‑матрицу, поэтому клавиша, удерживаемая при нажатии RESET, видна уже
   загружающейся странице 0 (иначе §5 не работал бы), и он же снимает/держит `reset` Z80.
4. Дальше уже сама страница 0 поднимает диспетчер (`0xFF77 ← 0xAB`), программирует карты памяти и
   решает, куда передать управление (меню, BASIC, TR-DOS, другая прошивка, CMOS Setup, демо,
   отладчик).

Практическое следствие: до перепрограммирования карт памяти доступна **только** эта страница,
поэтому её код и начинается с `DI` + настройки стека/окон без единого `PUSH`.

Проверить раскладку можно по самому образу (в `zxevo_fe.rom` страница 0 — это `services_fe.rom`,
вариант с `-D DOS_FE`):

```bash
python3 -c "d=open('rom/zxevo_fe.rom','rb').read(); \
print(d[0x7FFF8:0x7FFF8+6])        # b'HEGLUK' — конец services.rom/services_fe.rom
print(d[0x7C000:0x7C004].hex())    # f3 c3 01 01 = DI: JP 0x0101 (INITPAGE0)"
```

| Выход              | `services.rom` (без `DOS_FE`), `services_fe.rom` (с `-D DOS_FE`)                             |

## 3. Карта страницы

| Адрес    | Метка                         | Содержимое                                                                       |
| -------- | ----------------------------- | -------------------------------------------------------------------------------- |
| `0x0000` | —                             | `DI`; `JP INITPAGE0`                                                             |
| `0x0008` | —                             | `NOP`; `JP DOS2RST8` — вход `RST 8`                                              |
| `0x0014` | `ADR_SEL_ROM`                 | `OUT (C),A`; `NOP`; `RET` — переключить страницу и вернуться                     |
| `0x0038` | —                             | `EI`; `RET` — обработчик прерываний (пустой)                                     |
| `0x0066` | —                             | `NOP` — вектор NMI                                                               |
| `0x0080` | `DEC40`                       | распаковщик (`include ../../dec40.a80`) — общий `UNPACK` для всех страниц        |
| `0x00FF` | —                             | `DW 0x0038` (поле «адрес IM 1»)                                                  |
| `0x0101` | `INITPAGE0`                   | **главная точка входа** — вся логика сброса                                      |
| `0x0333` | `RAM_CODE`                    | код, который выполняется уже из ОЗУ (0x5C80) при выходе из сервиса               |
| `0x037B` | `ERAM_CODE`, `READCMOS`       | конец переносимого кода; чтение ячейки CMOS (H → L/A)                            |
| `0x0388` | `RES_AUTOBOOT`                | сброс режима автозапуска в CMOS (`0xE7`)                                         |
| `0x0398` | `RES_REZIDENT`                | сброс резидента в CMOS (`0xEC`, бит 2)                                           |
| `0x03BF` | `CMP_REZIDENT`                | проверка и запуск резидента Honey Commander                                      |
| `0x03ED` | `BONUADR`                     | упакованный CMOS Setup (`../../mainmenu/cmosset_pack.rom`)                       |
| `0x3CE8` | `EDOS2RST8`                   | **возврат из `RST 8`**: восстановление регистров                                 |
| `0x3CF6` | `DOS2RST8`                    | **вход `RST 8`**: формирование кадра и переход в обработчик ОЗУ                  |
| `0x3D2D` | —                             | `OUT (C),A`                                                                      |
| `0x3D2F` | —                             | `NOP`; `RET` — обязательная точка входа сервисной страницы (контракт Custom ROM) |
| `0x3D31` | `DEMO`                        | код инициализации + `grass.bin` (демо «GRASS» by PSB^Hallowen)                   |
| `0x3F38` | `LDIR4PROFROM`, `JMP2PROFROM` | переход в ProfROM (код копируется в 0x8000)                                      |
| `0x3F5D` | `PAGES_CONF`                  | основная конфигурация окон (2 маппера + целевая страница)                        |
| `0x3F66` | `PAGES_CONFGLUK`              | конфигурация для GLUK                                                            |
| `0x3F6F` | `PAGES_PROFROM`               | конфигурация для EVO ProfROM                                                     |
| `0x3F78` | `PAGES_CUSTOM`                | конфигурация для пользовательской прошивки (64 К)                                |
| `0x3F81` | `TRSTPAL`                     | палитра Spectrum‑режима (16 байт)                                                |
| `0x3FF8` | —                             | `"HEGLUK"`, `0x3FFE` — `DATA_VERS`                                               |

Таблицы конфигурации (по 9 байт):

```
PAGES_CONF       FF 7D 7A 83  FF 7D 7A 00  81     ; окна 0..3 маппера 0, окна 0..3 маппера 1, целевая страница
PAGES_CONFGLUK   FF 7D 7A 97  FF 7D 7A 00  95     ; CONF4GLUK   = 0x94
PAGES_PROFROM    FF 7D 7A 93  FF 7D 7A 00  91     ; CONF4PROF   = 0x90
PAGES_CUSTOM     FF 7D 7A 9F  FF 7D 7A 00  9D     ; CONF4CUSTOM = 0x9C
```

Первые 8 байт пишутся в регистры окон (по 4 на каждый маппер), 9‑й — номер страницы, с которым окно
0 включается непосредственно перед передачей управления сервисной странице (его биты 5‑2
сравниваются с `CONF4GLUK & 0x3F`, `CONF4CUSTOM & 0x3F` и т.д.).

## 4. Инициализация (`INITPAGE0`, 0x0101)

```
        LD SP,DEPKADR        ; 0x6000
        LD IY,0x5C3A
        LD A,0x3F
        LD I,A               ; I=0x3F (обработчик прерываний в конце страницы)
        IM 1
        XOR A
        OUT (0xFE),A         ; бордюр/звук — в ноль
        LD HL,PAGES_CONF
        LD BC,0xBC77         ; служебный регистр конфигурации ПЗУ
        LD A,2
        OUT (C),A
        LD DE,0x103F         ; D — бит выбора маппера, E — шаг для перебора портов окон
.L1     LD BC,CONF_128      ; 0x7FFD: выбрать маппер 0 / 1
        OUT (C),D
        LD BC,LOW(WIN_A0)    ; 0x00F7
.L2     OUTI                 ; записать очередную страницу в окно
        LD A,B : SUB E : LD B,A
        JR NZ,.L2
        LD BC,CONF_128
        LD A,D : XOR 0x10 : LD D,A
        JR Z,.L1             ; оба маппера
        LD BC,0xFF77
        LD A,0xAB
        OUT (C),A            ; видеорежим ZX + турбо
```

Итого по шагам:

1. **Стек** — `0x6000` (он же адрес загрузки главного меню), `IY` = стандартные BASIC‑переменные,
   `I` = 0x3F, `IM 1`.
2. **Бордюр/звук** — `OUT (0xFE),0`.
3. **Обе таблицы страниц** проецирования заполняются из выбранной таблицы `PAGES_*` (4 окна × 2
   маппера), `0xBC77 ← 2` — служебный регистр конфигурации ПЗУ.
4. **Палитра/режим** — `0xFF77 ← 0xAB` (ZX‑экран, турбо вкл).
5. **Инициализация сервиса** — `ROM_RST81:0x0040` (`INSTALL_NMIRST`) через `PEC_ON M_SHADOW_BF` +
   `PUSH адрес возврата` + `WIN_A0 ← ROM_RST81` + `JP ADR_SEL_ROM`. После возврата — `INIT_CMOS`
   (`RST 8` `_CMOS_RW,_INIT_CMOS`).
6. **Проверка клавиши `0`** (если нажата — `RES_REZIDENT` + `RES_AUTOBOOT`, остаёмся на ERS) и
   **выбор целевого ПЗУ по CMOS `0xED`** (см. §6) с загрузкой соответствующей таблицы `PAGES_*`.
7. **Ожидание отпускания «0»**, повторное программирование окон уже из выбранной таблицы,
   `IXH ← последний байт таблицы` (целевая страница).
8. **Установка палитры Spectrum** (`TRSTPAL` через `WIN_A3`/`0xBD77`/`0xFF`) на время сброса.
9. **Ветвление по `IXH`**:
   - `AND 0x3C = 0` → основная прошивка ERS (**`.L11`**);
   - `= CONF4GLUK & 0x3F` или `= CONF4CUSTOM & 0x3F` (**`.L10`**) → включить эту страницу в окно 0 и
     `JP 0x3D2D` этой страницы (там `OUT (C),A; NOP; RET` → далее `0x3D2F` → `0`);
   - иначе → `LDIR4PROFROM` (ProfROM: код `JMP2PROFROM` копируется в 0x8000, включается
     ProfROM‑страница, `JP 0x8000`).
10. **`.L11` — ветка ERS**:
    - CMOS `0xED`: принудительно сбросить биты «куда сбрасывать» (всегда ERS);
    - подготовить DOS: в FE‑сборке распаковать `UNP_DOS_FE` в страницу `RAM_EVODOS`
      (`WIN_A3 ← ROM_RST82`, `WIN_P2 ← RAM_EVODOS`), иначе скопировать страницу `ROM_ADD_DOS`
      (`LDIR` 16 К в `RAM_EVODOS`);
    - `WIN_A2 ← 0x7D`, `WIN_A3 ← 0xFF`;
    - `CMP_REZIDENT` — проверка резидента и передача ему управления;
    - **сканирование клавиатуры** (`.L12`, см. §5) и переход на выбранную цель (§4.1).

### 4.1. Переход к выбранной цели

Общая схема: адрес цели кладётся в стек (`PUSH`) **до** `RAM_CODE`, чтобы финальный `RET` в
перенесённом коде ушёл по нужному адресу.

- **Главное меню ERS** (`.L13`) — `SP = 0x6000`, `DE = 0x6000`, `IXL = 1`, `A = 0x10`; в окно 0
  включается `ROM_MAINMENU`, `RET` на адрес `0x0101` = `UNP_MAINMENU`, тот распаковывает меню в
  `0x6000` и возвращает управление на `.L14`; `.L14`, если клавиши уже отпущены, кладёт в стек
  `0x6000` и уходит в `.L18`/`RAM_CODE`, откуда `RET` попадает в распакованное меню.
- **BASIC 128** (`.L13`, нажат `CS`) — `IXL = 0`, `A = 0x00`, в стек кладётся `0x0000`.
- **BASIC 48** (нажат `SS`) — `IXL = 0`, `A = 0x30`, в стек кладётся `0x0000`.
- **TR‑DOS** (нажат `SPACE`) — `IXL = 0`, `A = 0x10`, в стек кладётся `0x3D2F`.
- **CMOS Setup / тест клавиатуры** (`.L15`/`.L16`) — `SCF`, `A = 0x10`, `BONUADR` распаковывается в
  `0x6000`, в стек кладётся `0x6000`.
- **GLUK / Custom ROM** (`.L10`) — включается страница `IXH` в окно 0 и выполняется `JP 0x3D2D` этой
  страницы (`OUT (C),A; NOP; RET` → далее `0x3D2F` → `0`).
- **ProfROM** — `LDIR4PROFROM`: код `JMP2PROFROM` копируется в `0x8000`, включается `0xBC77 ← 3`,
  окно 0 ← `IXH`, `JP 0x8000`.

### 4.2. `RAM_CODE` (0x0333, исполняется по адресу 0x5C80)

Код копируется `LDDR` в `0x5C80` (сразу под системные переменные BASIC) и работает уже из ОЗУ —
потому что ему нужно переключать мапперы. Делает:

- `PENT_CONF (0xEFF7)` — модель памяти: для основной прошивки `0x10` (доступ ко всему первому
  мегабайту через `0xEFF7`), иначе — из CMOS `0xEC` (1 Мб / 48 К / 128 К) с учётом турбо‑битов;
- `0x7FFD ← 0` — включить маппер 0;
- окно 0 ← значение `IXH` (последний байт таблицы `PAGES_*`);
- `0xFF77 ← D` — турбо (`0xA3` + бит 14 МГц из CMOS `0xED`);
- `0x7FFD ← A'` — целевое значение порта: `0x00` (BASIC 128), `0x30` (BASIC 48 + экран 0), `0x10`
  (BASIC 48 / TR‑DOS);
- `RET` — переход на адрес, ранее положенный в стек (меню, BASIC, TR‑DOS, cmosset).

## 5. Клавиши, удерживаемые при сбросе

Опрос идёт по «полурядам» ZX‑клавиатуры через порт `0xFE` (в скобках — реальная проверка в коде):

| Клавиша (полуряд)                                       | Что происходит                                                                                                                                                                                                                                |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0` (`0xEFFE`, бит 0)                                   | принудительно выключить резидента (`RES_REZIDENT`) и автозапуск (`RES_AUTOBOOT`), остаться на основной прошивке; далее ожидание отпускания                                                                                                    |
| `CS` — CAPS SHIFT (`0xFEFE`, бит 0)                     | сброс в **BASIC 128** (`A = 0`, возврат на `0x0000`)                                                                                                                                                                                          |
| `SS` — SYMBOL SHIFT (`0x7FFE`, бит 1)                   | сброс в **BASIC 48** (`A = 0x30`, возврат на `0x0000`)                                                                                                                                                                                        |
| `SPACE` (`0x7FFE`, бит 0)                               | сброс в **TR‑DOS** (`A = 0x10`, возврат на `0x3D2F`)                                                                                                                                                                                          |
| `D` (`0xFDFE`, бит 2)                                   | запуск демо **GRASS** (`DEMO`, «GRASS by PSB^Hallowen»)                                                                                                                                                                                       |
| «вторая клавиша» полуряда `0 9 8 7 6` (`0xEFFE`, бит 1) | вход в **внутренний отладчик**: `WIN_P2 ← 0`, `DEBUG_ONOFF ← 0x80`, генерация NMI через `PEVO_CONF` (`M_NMI_BF`), `HALT`, затем ожидание отпускания клавиш. В комментарии исходника это названо «проверка кнопки 6», хотя код проверяет бит 1 |
| **две и более** клавиши одновременно                    | тест клавиатуры: `BONUADR` (упакованный `cmosset_pack.rom`) распаковывается `DEC40` в `0x6000` и запускается с установленным флагом переноса — в `cmosset` это `JP C,TSTKEY` (интерактивная проверка матрицы клавиатуры)                      |
| ничего не нажато                                        | основная прошивка → главное меню ERS                                                                                                                                                                                                          |

Дополнительно: если после распаковки главного меню клавиши ещё удерживаются, `.L14` запускает
`cmosset` (`0x6000`) повторно. При этом флаг переноса сброшен, поэтому работают собственные ветки
программы: `C` — таблица цветов, `S` — редактор CMOS, любая другая клавиша — страница помощи
(`PRHELP`).

Особенности реализации:

- сканирование идёт по всем восьми «полурядам»
  (`0xFEFE, 0xFDFE, 0xFBFE, 0xF7FE, 0xEFFE, 0xDFFE, 0xBFFE, 0x7FFE`), `C` считает число нажатых
  клавиш (`LD BC,0xFEFF` + `INC C` на каждую нажатую); после цикла `DEC C; JP P,.L15` — «две и
  более»;
- проверки отдельных клавиш идут после этого, поэтому `CS`/`SS`/`SPACE`/`D` имеют приоритет над
  «главным меню», но не над «две и более клавиши»;
- проверка отладочника (бит 1 полуряда `0xEFFE`) выполняется сразу после проверки `0` и **до**
  выбора ПЗУ по CMOS;
- после выбора все клавиши должны быть отпущены (циклы ожидания), иначе сброс «залипнет».

## 6. Выбор прошивки для сброса

Приоритет: **клавиша `0`** (принудительно ERS) → иначе **CMOS `0xED`, биты 1‑0**:

| Значение | Прошивка            | Таблица          | Ветка                                         |
| -------- | ------------------- | ---------------- | --------------------------------------------- |
| 0        | EVO Reset Service   | `PAGES_CONF`     | `.L11`                                        |
| 1        | GLUK Service        | `PAGES_CONFGLUK` | `.L10` → `JP 0x3D2D` страницы `CONF4GLUK+1`   |
| 2        | EVO ProfROM (128 К) | `PAGES_PROFROM`  | `LDIR4PROFROM` → `JMP2PROFROM` в 0x8000       |
| 3        | Custom ROM (64 К)   | `PAGES_CUSTOM`   | `.L10` → `JP 0x3D2D` страницы `CONF4CUSTOM+1` |

Константы (`rom/global_vars.a80`): `CONF4PROF = 0x90`, `CONF4GLUK = 0x94`, `CONF4CUSTOM = 0x9C`. Для
Custom/GLUK сервисная страница обязана иметь по смещению `0x3D2F` команды `NOP; RET` (коды `00 C9`)
— в саму `services.rom` они тоже продублированы (`0x3D2D`/`0x3D2F`). Возврат к основной прошивке —
удержать `0` и нажать RESET.

## 7. Автозапуск и резидент

- **Автозапуск** (CMOS `0xE7`, биты 1‑0: `0` — выкл, `1` — `SD_BOOT.$C`, `2` — по файлу INI). При
  удержании `0` при сбросе `RES_AUTOBOOT` очищает эти биты. Сам запуск выполняет главное меню
  (`AUTORUNBOOT`, один раз после сброса).
- **Резидент Honey Commander** (CMOS `0xEC`, бит 2 — разрешение; `0xE8`, бит 7 — «порча» для
  однократного запуска). `CMP_REZIDENT`:
  1. если разрешение снято — выход;
  2. включает `WIN_A3 ← 0x1F | 0x7F` (страница `0x1F` верхней памяти);
  3. проверяет, что первый байт — `C3` (`JP`), считает сумму всех байтов страницы по модулю 256
     (должна быть равна 1), затем байт `0xFFFF` — `0xAA`, байт `0xFFFE` — `0x55`;
  4. при совпадении всех условий — `WIN_A0 ← 6` (`B_PORT77`/`OUT 0x4177`) и переход на адрес
     `0xC000` (страница резидента), иначе восстанавливает `WIN_A3 ← 0xFF`.

## 8. Стабы `RST 8` на этой странице

`services.rom` — одна из страниц, которая может стоять в окне 0 в момент вызова `RST 8` (главное
меню, загрузчики HOBETA/TAP, Perfect Commander). Поэтому она содержит полный набор стабов, требуемых
обработчиком:

| Адрес    | Что делает                                                                                                                                                                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `0x0008` | `NOP`; `JP DOS2RST8`                                                                                                                                                                                                                                                                 |
| `0x0014` | `OUT (C),A; NOP; RET` (`ADR_SEL_ROM`)                                                                                                                                                                                                                                                |
| `0x3CE8` | `EDOS2RST8`: `OUT (PEVO_CONF),A` из `L`, затем восстановление `DE`, `HL`, `AF`, `BC`, `AF`, `EX (SP),HL`, `RET`                                                                                                                                                                      |
| `0x3CF6` | `DOS2RST8`: `EX (SP),HL`, сохранение `AF`, `BC`, `R`, адреса возврата, `DE`; чтение текущих страниц и битов `RAMNROM`/`DOS7FFD`; `WIN_P0 ← 0` (страница ОЗУ `RAM_NMI`) — после чего выполнение продолжается по тому же адресу `0x0014` уже в копии обработчика из ОЗУ (`JP RAMSEL1`) |

Подробная схема вызова и возврата — в [`../page5/README.md`](../page5/README.md), §5.

## 9. Прочее содержимое

| Блок                                  | Назначение                                                                                                                                             |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `DEC40` (0x0080)                      | распаковщик (`mhmt -mlz`); адрес `0x0080` — общий `UNPACK` для страниц 5..9                                                                            |
| `BONUADR` (0x03ED)                    | упакованный «CMOS Setup & HELP» (`rom/mainmenu/cmosset_pack.rom`): редактор ячеек CMOS 80×25, страница помощи, таблица цветов, тест матрицы клавиатуры |
| `DEMO` (0x3D31) + `grass.bin`         | демонстрация «GRASS»: включается `CONF_128 ← 0x10` и `EI`, далее исполняется картинка‑эффект                                                           |

| `TRSTPAL` (0x3F81)                    | палитра Spectrum‑режима (значения собираются из битов `M_R_*`/`M_G_*`/`M_B_*`)                                                                         |

## 10. Сборка

```bash
cd rom/page0/source
./build.sh
```

Скрипт выполняет два прохода ASL:

```bash
asl -U -L -x -olist services.lst services.a80
p2bin services.p ../services.rom -r '$-$' -k
asl -U -L -x -olist services_fe.lst -D DOS_FE services.a80
p2bin services_fe.p ../services_fe.rom -r '$-$' -k
```

`-D DOS_FE` включает вариант с распаковкой эмулятора ВГ (`UNP_DOS_FE`). В базовом варианте
копируется страница `ROM_ADD_DOS`. Полная сборка — `rom/build_full.sh`.

## 11. Связь со страницей 5 (`RST 8 Service`)

```
RESET
  └─ services.rom (стр. 0, окно 0)
       ├─ программирование окон/палитры
       ├─ INSTALL_NMIRST (RST81:0x40, rom/page5)  ← инициализация RST 8/NMI, CMOS, шрифт, HDD
       ├─ клавиши / CMOS → выбор прошивки
       └─ основная ветка:
            ├─ ROM_MAINMENU (стр. 5, rom/page5/source/mainmenu.a80)
            │     └─ распаковка главного меню ERS в 0x6000 и запуск
            └─ далее меню и DOS общаются с сервисом через RST 8
```

Точки соприкосновения:

| Что              | Куда                                                                |
| ---------------- | ------------------------------------------------------------------- |
| `INSTALL_NMIRST` | `ROM_RST81`, адрес `0x0040`                                         |
| `RST 8` (вход)   | `0x0008` → `DOS2RST8` → обработчик в `RAM_NMI` → `ROM_RST83:0x002C` |
| `RST 8` (выход)  | `ROM_RST83:EXIT_RST8` → `0x3CE8` этой страницы                      |
| Главное меню ERS | `ROM_MAINMENU`, вход `0x0101` (`UNP_MAINMENU`)                      |
| CMOS Setup       | `BONUADR` (упакованный `cmosset_pack.rom`)                          |
| Резидент         | `CMP_REZIDENT` → страница `0x1F`                                    |

## 12. Ограничения и нюансы

- Страница «одноразовая» по смыслу: после передачи управления в меню/ПЗУ она остаётся в окне 0
  только как поставщик стабов `RST 8` — её код инициализации больше не вызывается.
- `PAGES_CONF` для основной прошивки менять не рекомендуется (комментарий в исходнике); при ошибке
  конфигурации система просто не запустится.
- Внутренний отладчик доступен только при нажатой клавише на сбросе и работает через NMI; при
  `BUILD_DEBUG=0` (текущая сборка) пункт `D.Debugger` в меню MAGIC отсутствует.
- Демо `GRASS` и CMOS Setup запускаются «поверх» сервиса — без инициализации DOS.
- Проверка резидента считает сумму по всей странице `0x1F` до `0xFFFF`, поэтому резидент должен быть
  собран с корректной суммой и маркером `AA 55` в конце.
