# ZX Evolution

[English](README.en.md) | [Русский](README.ru.md)

Форк официального SVN-репозитория `pentevo`. Добавляет конфигурацию z88dk для разработки
на C под BaseConf и автоматические тесты стандартной библиотеки z88dk и возможностей BaseConf.
Для тестов нужна актуальная сборка ZEsarUX с исправлениями совместимости BaseConf.
В репозитории также есть полностью переработанный справочник разработчика ZX Evolution.

A fork of the official `pentevo` SVN repository. It adds a z88dk target for C development
on BaseConf and automated tests for the z88dk standard library and BaseConf features.
The tests require a current ZEsarUX build with the BaseConf compatibility fixes.
The repository also includes a fully revised ZX Evolution developer reference.
